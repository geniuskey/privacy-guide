오류 신고와 기여를 환영합니다. 자세한 내용은 저장소의 [CONTRIBUTING.md](https://github.com/geniuskey/privacy-guide/blob/main/CONTRIBUTING.md)를 참고하세요.

- **법적 근거가 틀렸다면**: 이슈에 공식 원문 링크와 조항을 함께 적어 주세요.
- **문서를 고친다면**: 문서의 9개 섹션 순서와 frontmatter 스키마를 지키고 `npm run validate:content`를 통과해야 합니다.
- **법률 전문가라면**: `review-required` 문서의 검토에 참여해 주세요. 검토를 마친 문서에는 검토자와 검토일이 표시됩니다.

## 0.2.0 — 2026-10-23

- 상세 검색: 카테고리·검토 상태·근거 출처·태그 필터.
- 행정기관 안내서 7종의 게시 버전·URL을 개인정보보호위원회 안내서 게시판에서 확인해 출처 레지스트리에 반영. 「개인정보 보호 가이드라인(인사·노무 편)」(2023.1.)은 게시판에서 **과거 안내서**로 분류되어 있어 문서에 표시. 「개인정보의 안전성 확보조치 기준 안내서」(2025.11.)는 현행 고시(2026.7.1. 시행)보다 먼저 발행된 판임을 표시.
- 가명정보 처리 가이드라인(2026.3.), 전송요구권 제도 안내서(2026.6.), 신용정보법·전자상거래법·행정기본법·위치정보법을 출처 레지스트리에 추가.
- 출처 변경 감지: 안내서는 게시판 검색 결과의 게시글 번호로 비교. Skill 원문 발췌 재생성 스크립트와 조문 인용 일관성 테스트 추가.
- Skill: PR 검토 예시, 설치 스크립트.

## 0.1.0 — 2026-10-23

- 최초 공개(MVP). 10개 카테고리 핵심 문서, 자가진단, 구현 예제, `kr-privacy-review` Skill, 출처 변경 감지 포함.
- 기준 법령: 「개인정보 보호법」 법률 제21445호(2026.9.11. 시행), 같은 법 시행령 대통령령 제36671호(2026.9.11. 시행), 「개인정보의 안전성 확보조치 기준」 개인정보보호위원회 고시 제2026-9호(2026.7.1. 시행).
- 모든 문서는 법률 전문가 검토 전(`review-required`) 상태입니다.

# 테스트 케이스 템플릿

검토 보고서의 "9. 테스트 케이스"는 아래 형식으로 씁니다. 실행 가능한 예시는 가이드 저장소의 `examples/python-fastapi/tests`, `examples/typescript/test`에 있습니다.

```text
ID: TC-<영역>-<번호>
목적: <무엇을 막는지>
전제: <사용자·역할·데이터 상태>
절차: <요청/동작>
기대 결과: <상태 코드, 응답 필드, 로그, 감사기록>
근거: <[법률]/[고시]/[표준]/[권장] 조항>
```

## 템플릿

| 영역 | 테스트 | 기대 결과 |
| --- | --- | --- |
| 객체 권한 | 사용자 A가 사용자 B의 리소스 ID로 GET/PUT/DELETE | 404 또는 403, B의 데이터가 응답·로그에 없음 |
| 역할 권한 | 권한 없는 역할로 개인정보 API 호출 | 403, 접근 시도가 감사로그에 남음 |
| 관리자 분리 | 시스템 관리자(개인정보 열람 권한 없음)가 회원 상세 조회 | 403. break-glass 사용 시 사유·만료 시각·감사로그 필수 |
| 최소 응답 | 응답 JSON 키 집합 검사 | 허용목록 외 필드(password_hash, rrn 등) 없음 |
| 로그 마스킹 | 이메일·전화번호·주민등록번호·카드번호·Bearer 토큰을 포함한 로그 출력 | 로그 출력에 원문 없음 |
| 접속기록 | 개인정보 조회·다운로드 수행 | 계정·시각·접속지·처리 내용·정보주체 식별값이 기록됨, 변조 시 검증 실패 |
| 인증 실패 | 비밀번호 N회 연속 실패 | 계정 또는 접근 제한 |
| 세션 | 로그인 전후 세션 ID 비교, 유휴 시간 경과 후 요청 | 로그인 시 ID 변경, 만료 후 401 |
| 보존·파기 | 보존기간 경과 시점으로 시계를 옮기고 파기 배치 실행 | 대상 삭제, 법정 보존 대상은 분리 저장소에만 존재, 파기 기록 생성 |
| 삭제 요청 | 탈퇴 후 주 DB·캐시·검색 인덱스·벡터 DB 조회 | 결과 없음 |
| 내보내기 | 본인 데이터 내보내기 | 본인 데이터만 포함, 다른 사용자 데이터 없음 |
| LLM 필터 | 개인정보가 담긴 입력으로 기능 실행, 가짜 LLM 클라이언트로 payload 캡처 | payload에 원문 개인정보 없음, 허용목록 필드만 존재 |
| 다운로드 | 대량 내보내기 | 접속기록 생성(고시 제8조), 사유 입력·건수 제한([권장]) |
